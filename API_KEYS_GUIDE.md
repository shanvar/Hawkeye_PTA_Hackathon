# Руководство по API ключам

## Обзор

Система AI Инкубатора теперь поддерживает два режима работы с API ключами:

1. **🔑 Готовые ключи** - использование предустановленных API ключей
2. **⚙️ Свой ключ** - использование ваших собственных API ключей

## Режим "Готовые ключи"

### Преимущества:
- ✅ Быстрый старт без настройки
- ✅ Автоматическое переключение между ключами
- ✅ Мониторинг нагрузки на ключи
- ✅ Не требует регистрации в API сервисах

### Как использовать:
1. Выберите AI провайдера (Google Gemini или OpenAI)
2. Нажмите кнопку "🔑 Готовые ключи"
3. Выберите доступный ключ из списка
4. Нажмите "🧪 Тестировать выбранный ключ" для проверки

### Статусы ключей:
- 🟢 **Низкая нагрузка** - ключ доступен для использования
- 🟡 **Средняя нагрузка** - ключ работает, но нагрузка повышена
- 🔴 **Высокая нагрузка** - ключ временно недоступен

## Режим "Свой ключ"

### Преимущества:
- ✅ Полный контроль над API ключами
- ✅ Нет ограничений на использование
- ✅ Приватность и безопасность

### Как настроить:

#### Для Google Gemini:
1. Перейдите на [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Создайте новый API ключ
3. Выберите режим "⚙️ Свой ключ"
4. Вставьте ваш ключ в поле "Google AI API ключ"
5. Нажмите "Сохранить" и "Тест"

#### Для OpenAI:
1. Перейдите на [OpenAI Platform](https://platform.openai.com/api-keys)
2. Создайте новый API ключ
3. Выберите режим "⚙️ Свой ключ"
4. Вставьте ваш ключ в поле "OpenAI API ключ"
5. Нажмите "Сохранить" и "Тест"

## Переключение между режимами

Вы можете переключаться между режимами в любое время:
- Нажмите "🔑 Готовые ключи" для использования предустановленных ключей
- Нажмите "⚙️ Свой ключ" для использования ваших ключей

## Безопасность

### Готовые ключи:
- Ключи хранятся в отдельном файле `api-keys.json`
- Доступ контролируется администратором
- Автоматическое переключение при превышении лимитов

### Свои ключи:
- Ключи сохраняются только в локальном хранилище браузера
- Не передаются на сервер
- Полная приватность

## Устранение неполадок

### Ошибка "API ключ не найден":
1. Проверьте, что выбран правильный режим
2. Убедитесь, что ключ сохранен
3. Попробуйте протестировать ключ

### Ошибка "Превышен лимит запросов":
1. В режиме готовых ключей - система автоматически переключится на другой ключ
2. В режиме своих ключей - подождите или обновите лимиты в вашем аккаунте

### Ошибка "Неверный API ключ":
1. Проверьте правильность ключа
2. Убедитесь, что ключ активен в вашем аккаунте
3. Проверьте права доступа к API

## Техническая информация

### Файлы системы:
- `api-keys.json` - конфигурация готовых ключей
- `js/api-key-manager.js` - менеджер API ключей
- `js/api.js` - функции работы с API

### Сохранение настроек:
- Режим ключей сохраняется в `localStorage`
- Выбранный провайдер сохраняется в `localStorage`
- Пользовательские ключи сохраняются в `localStorage`

## Поддержка

При возникновении проблем:
1. Проверьте консоль браузера на наличие ошибок
2. Убедитесь, что все файлы загружены корректно
3. Попробуйте очистить кеш браузера
4. Обратитесь к администратору системы
