# 🚀 Быстрый старт: Система управления состоянием

## Что нового?

Теперь ваше приложение автоматически сохраняет прогресс и позволяет откатываться назад!

### ✨ Основные возможности

1. **🔄 Автосохранение** - каждые 5 секунд
2. **↶ Откат** - вернуться на шаг назад
3. **💾 Экспорт/Импорт** - сохранить/загрузить прогресс
4. **📊 Мониторинг** - следить за состоянием

## Как использовать

### Откат изменений
- **В заголовке модуля**: Нажмите кнопку "↶ Откат"
- **В админ панели**: Раздел "Управление состоянием" → "↶ Откат на шаг назад"

### Экспорт прогресса
1. Откройте админ панель (🔧 Админ панель)
2. Нажмите "📤 Экспорт состояния"
3. Файл скачается автоматически

### Импорт прогресса
1. В админ панели нажмите "📥 Импорт состояния"
2. Выберите сохраненный файл
3. Прогресс восстановится автоматически

### Очистка истории
- В админ панели: "🗑️ Очистить историю"

## Техническая информация

### Файлы системы
- `js/state-manager.js` - основная логика
- `js/admin.js` - функции админ панели
- `js/ui.js` - уведомления
- `Styles.css` - стили кнопок и уведомлений

### Локальное хранение
- `aiIncubatorCurrentState` - текущее состояние
- `aiIncubatorHistory` - история (до 50 состояний)
- `aiIncubatorProgress` - совместимость со старой системой

### Автоматические события
Снапшоты создаются при:
- Завершении топика
- Переходе к модулю
- Изменении прогресса
- Каждые 5 секунд

## Устранение проблем

### Откат не работает
- Убедитесь, что есть сохраненные состояния
- Проверьте консоль браузера
- Попробуйте очистить историю

### Импорт не работает
- Проверьте формат файла (должен быть JSON)
- Убедитесь, что файл не поврежден
- Попробуйте экспортировать текущее состояние

### Медленная работа
- Очистите историю состояний
- Уменьшите частоту автосохранения
- Проверьте размер localStorage

## Настройки для разработчиков

```javascript
// Изменить частоту автосохранения (в миллисекундах)
window.stateManager.autoSaveDelay = 10000; // 10 секунд

// Изменить размер истории
window.stateManager.maxHistorySize = 100; // 100 состояний

// Отключить автосохранение
window.stateManager.stopAutoSave();

// Включить автосохранение
window.stateManager.startAutoSave();

// Создать снапшот вручную
window.stateManager.createSnapshot();
```
