# Система управления состоянием AI Инкубатора

## Обзор

Система управления состоянием позволяет пользователям сохранять прогресс обучения и восстанавливать его даже после закрытия браузера. Также предоставляется возможность отката на один шаг назад в истории изменений.

## Основные возможности

### 🔄 Автосохранение
- Автоматическое создание снапшотов состояния каждые 5 секунд
- Сохранение только при изменении состояния (оптимизация)
- Максимум 50 состояний в истории

### ↩️ Откат изменений
- Откат на один шаг назад в истории
- Восстановление всех данных: модули, топики, прогресс, чат
- Кнопка отката в заголовке модуля и админ панели

### 💾 Экспорт/Импорт
- Экспорт полного состояния в JSON файл
- Импорт состояния из файла
- Сохранение истории изменений

### 📊 Мониторинг
- Отображение количества состояний в истории
- Время последнего снапшота
- Уведомления о важных событиях

## Использование

### Откат на шаг назад
1. **В основном интерфейсе**: Нажмите кнопку "↶ Откат" в заголовке модуля
2. **В админ панели**: Нажмите "↶ Откат на шаг назад" в разделе "Управление состоянием"

### Экспорт состояния
1. Откройте админ панель (🔧 Админ панель)
2. В разделе "Управление состоянием" нажмите "📤 Экспорт состояния"
3. Файл будет автоматически скачан с именем `ai-incubator-state-YYYY-MM-DD.json`

### Импорт состояния
1. Откройте админ панель
2. В разделе "Управление состоянием" нажмите "📥 Импорт состояния"
3. Выберите JSON файл с сохраненным состоянием
4. Состояние будет восстановлено автоматически

### Очистка истории
1. В админ панели нажмите "🗑️ Очистить историю"
2. Все сохраненные состояния будут удалены
3. Текущее состояние останется

## Технические детали

### Структура данных
```javascript
{
  timestamp: Date.now(),
  state: {
    currentModule: 0,
    modules: [...],
    projectData: {...},
    userIdeaText: "...",
    // ... другие поля состояния
  },
  description: "Модуль: Валидация идеи (2/5 топиков)"
}
```

### Локальное хранение
- `aiIncubatorCurrentState` - текущее состояние
- `aiIncubatorHistory` - история состояний
- `aiIncubatorProgress` - совместимость со старой системой

### Автоматические события
Снапшоты создаются автоматически при:
- Завершении топика
- Переходе к следующему модулю
- Изменении прогресса
- Каждые 5 секунд (автосохранение)

## Совместимость

### Миграция со старой системы
- Старые данные автоматически загружаются
- Новая система работает параллельно
- Обратная совместимость сохранена

### Браузерная поддержка
- Требуется поддержка localStorage
- Совместимо с современными браузерами
- Автоматическая обработка ошибок

## Безопасность

### Локальное хранение
- Все данные хранятся локально в браузере
- Никакие данные не отправляются на сервер
- Пользователь полностью контролирует свои данные

### Валидация данных
- Проверка целостности при загрузке
- Автоматическое восстановление при ошибках
- Резервные копии критических данных

## Устранение неполадок

### Проблемы с откатом
1. Убедитесь, что в истории есть состояния для отката
2. Проверьте консоль браузера на ошибки
3. Попробуйте очистить историю и начать заново

### Проблемы с импортом
1. Убедитесь, что файл имеет правильный формат JSON
2. Проверьте версию файла (должна быть 1.0)
3. Попробуйте экспортировать текущее состояние для сравнения

### Проблемы с производительностью
1. Очистите историю состояний
2. Уменьшите частоту автосохранения
3. Проверьте размер localStorage

## Настройки разработчика

### Изменение частоты автосохранения
```javascript
window.stateManager.autoSaveDelay = 10000; // 10 секунд
```

### Изменение размера истории
```javascript
window.stateManager.maxHistorySize = 100; // 100 состояний
```

### Отключение автосохранения
```javascript
window.stateManager.stopAutoSave();
```

### Ручное создание снапшота
```javascript
window.stateManager.createSnapshot();
```

## API функций

### Основные функции
- `undoLastAction()` - откат на шаг назад
- `getStateInfo()` - информация о состоянии
- `clearStateHistory()` - очистка истории
- `exportAppState()` - экспорт состояния
- `importAppState(file)` - импорт состояния

### Внутренние функции
- `createSnapshot()` - создание снапшота
- `restoreState(state)` - восстановление состояния
- `saveCurrentState()` - сохранение текущего состояния
- `loadLastState()` - загрузка последнего состояния
