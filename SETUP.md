# Настройка и запуск AI Инкубатора

## 🚀 Быстрый запуск

### Вариант 1: Python (рекомендуется)
```bash
# В папке проекта
python -m http.server 8000
```

### Вариант 2: Node.js
```bash
# Если установлен Node.js
npx http-server
```

### Вариант 3: Live Server (VS Code)
1. Установите расширение "Live Server"
2. Правый клик на `index.html` → "Open with Live Server"

## 🌐 Открыть в браузере
После запуска сервера откройте: `http://localhost:8000`

## ⚙️ Настройка API ключей

### Для Gemini AI (рекомендуется)
1. Перейдите на [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Создайте API ключ
3. В приложении введите ключ в поле "Gemini API Key"
4. Нажмите "Сохранить"

### Для OpenAI GPT-4
1. Перейдите на [OpenAI Platform](https://platform.openai.com/api-keys)
2. Создайте API ключ (начинается с `sk-`)
3. В приложении выберите "OpenAI GPT-4" в выпадающем списке
4. Введите ключ и нажмите "Сохранить"

## 🎯 Как использовать

1. **Запустите сервер** (см. выше)
2. **Откройте браузер** и перейдите на `http://localhost:8000`
3. **Настройте API ключ** в боковой панели
4. **Опишите вашу идею** и нажмите "Начать инкубацию"
5. **Проходите модули** по порядку

## 🛠 Разработка

### Добавление нового модуля:
1. Отредактируйте `js/config.js`
2. Добавьте новый модуль в массив `moduleConfig`

### Изменение стилей:
1. Отредактируйте `Styles.css`
2. Используйте CSS переменные для консистентности

### Добавление новых функций:
1. Создайте новый файл в папке `js/`
2. Подключите его в `index.html`

## 🐛 Устранение неполадок

### Проблема: "Не удается найти указанный путь"
**Решение**: Убедитесь, что вы находитесь в правильной папке проекта

### Проблема: API ключ не работает
**Решение**: 
- Проверьте правильность ключа
- Убедитесь, что у вас есть доступ к API
- Проверьте интернет-соединение

### Проблема: Страница не загружается
**Решение**:
- Проверьте консоль браузера (F12)
- Убедитесь, что все файлы на месте
- Проверьте, что сервер запущен

## 📞 Поддержка

При возникновении проблем:
1. Проверьте консоль браузера (F12)
2. Убедитесь в корректности API ключа
3. Проверьте подключение к интернету
4. Очистите localStorage если нужно: `localStorage.clear()`
