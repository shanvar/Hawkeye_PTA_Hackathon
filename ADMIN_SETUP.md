# Настройка системы API ключей для администратора

## Обзор

Система AI Инкубатора поддерживает два режима работы с API ключами:
- **Готовые ключи** - предустановленные ключи для быстрого старта
- **Пользовательские ключи** - собственные ключи пользователей

## Настройка готовых ключей

### 1. Создание файла api-keys.json

Создайте файл `api-keys.json` в корневой папке проекта:

```json
{
  "providers": {
    "openai": {
      "name": "OpenAI",
      "description": "GPT-4 и другие модели OpenAI",
      "keys": [
        {
          "id": "openai-1",
          "name": "OpenAI Key 1",
          "key": "sk-proj-your-actual-key-here",
          "status": "active",
          "usage": "low"
        }
      ]
    },
    "gemini": {
      "name": "Google Gemini",
      "description": "Gemini Pro и другие модели Google",
      "keys": [
        {
          "id": "gemini-1",
          "name": "Gemini Key 1",
          "key": "AIzaSy-your-actual-key-here",
          "status": "active",
          "usage": "low"
        }
      ]
    }
  },
  "settings": {
    "autoRotate": true,
    "maxUsagePerKey": 1000,
    "fallbackToCustom": true
  }
}
```

### 2. Структура ключа

Каждый ключ содержит следующие поля:

- `id` - уникальный идентификатор ключа
- `name` - отображаемое название ключа
- `key` - сам API ключ
- `status` - статус ключа (`active`, `inactive`, `error`)
- `usage` - уровень использования (`low`, `medium`, `high`)

### 3. Получение API ключей

#### OpenAI API ключи:
1. Зарегистрируйтесь на [OpenAI Platform](https://platform.openai.com/)
2. Перейдите в раздел API Keys
3. Создайте новый ключ
4. Скопируйте ключ (начинается с `sk-`)

#### Google Gemini API ключи:
1. Зарегистрируйтесь на [Google AI Studio](https://aistudio.google.com/)
2. Перейдите в раздел API Keys
3. Создайте новый ключ
4. Скопируйте ключ (начинается с `AIzaSy`)

### 4. Управление ключами

#### Добавление нового ключа:
```json
{
  "id": "openai-new",
  "name": "OpenAI New Key",
  "key": "sk-proj-new-key-here",
  "status": "active",
  "usage": "low"
}
```

#### Деактивация ключа:
```json
{
  "id": "openai-old",
  "name": "OpenAI Old Key",
  "key": "sk-proj-old-key-here",
  "status": "inactive",
  "usage": "high"
}
```

## Безопасность

### Рекомендации по безопасности:

1. **Не публикуйте реальные ключи** в публичных репозиториях
2. **Используйте переменные окружения** для продакшена
3. **Регулярно ротируйте ключи** для безопасности
4. **Мониторьте использование** ключей
5. **Устанавливайте лимиты** на использование

### Файл .gitignore

Добавьте в `.gitignore`:
```
api-keys.json
api-keys-prod.json
```

### Переменные окружения (для продакшена)

Создайте файл `api-keys-env.js`:
```javascript
// Загрузка ключей из переменных окружения
const apiKeys = {
  providers: {
    openai: {
      name: "OpenAI",
      keys: [
        {
          id: "openai-env",
          name: "OpenAI Environment Key",
          key: process.env.OPENAI_API_KEY,
          status: "active",
          usage: "low"
        }
      ]
    },
    gemini: {
      name: "Google Gemini",
      keys: [
        {
          id: "gemini-env",
          name: "Gemini Environment Key",
          key: process.env.GEMINI_API_KEY,
          status: "active",
          usage: "low"
        }
      ]
    }
  }
};
```

## Мониторинг и обслуживание

### 1. Мониторинг использования

Регулярно проверяйте:
- Количество запросов к каждому ключу
- Ошибки API (429, 403, 401)
- Время отклика API

### 2. Ротация ключей

При достижении лимитов:
1. Добавьте новый ключ в `api-keys.json`
2. Установите статус старого ключа в `inactive`
3. Обновите `usage` на `high`

### 3. Резервные ключи

Всегда держите несколько резервных ключей:
```json
{
  "id": "openai-backup",
  "name": "OpenAI Backup Key",
  "key": "sk-proj-backup-key",
  "status": "active",
  "usage": "low"
}
```

## Устранение неполадок

### Проблема: Ключи не загружаются
**Решение:**
1. Проверьте формат JSON в `api-keys.json`
2. Убедитесь, что файл доступен для чтения
3. Проверьте консоль браузера на ошибки

### Проблема: Ключи не работают
**Решение:**
1. Проверьте правильность ключей
2. Убедитесь, что ключи активны в аккаунтах
3. Проверьте лимиты использования

### Проблема: Высокая нагрузка на ключи
**Решение:**
1. Добавьте больше ключей
2. Увеличьте лимиты в аккаунтах
3. Настройте автоматическую ротацию

## Тестирование

### Локальное тестирование:
1. Создайте `api-keys-test.json` с тестовыми ключами
2. Запустите локальный сервер
3. Протестируйте оба режима работы

### Продакшен тестирование:
1. Разверните на тестовом сервере
2. Протестируйте с реальными ключами
3. Проверьте мониторинг и логи
