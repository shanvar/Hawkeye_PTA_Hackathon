# 📝 Руководство по системе промптов AI Инкубатора

## Обзор

Система промптов позволяет централизованно управлять всеми промптами приложения через JSON файл `prompts.json`. Это обеспечивает гибкость настройки и легкое обновление промптов без изменения кода.

## Структура файла prompts.json

### Основные разделы

```json
{
  "version": "1.0.0",
  "description": "Все промпты AI Инкубатора для удобной настройки",
  "lastUpdated": "2024-12-19",
  "prompts": {
    "modules": { ... },
    "chat": { ... },
    "validation": { ... },
    "dialog": { ... },
    "api": { ... }
  },
  "settings": { ... },
  "fallbacks": { ... },
  "metadata": { ... }
}
```

### Категории промптов

#### 1. **modules** - Системные промпты модулей
```json
{
  "validation": {
    "id": "validation",
    "title": "Валидация идеи",
    "systemPrompt": "Вы эксперт по валидации бизнес-идей..."
  }
}
```

#### 2. **chat** - Промпты для чата и обучения
```json
{
  "learningPlan": {
    "description": "Создание плана обучения для топика",
    "prompt": "Создай краткий план обучения..."
  },
  "answerEvaluation": {
    "description": "Оценка ответа пользователя",
    "prompt": "Оцените ответ пользователя..."
  }
}
```

#### 3. **validation** - Промпты для валидации
```json
{
  "generateQuestions": {
    "description": "Генерация контрольных вопросов",
    "prompt": "На основе следующей бизнес-идеи..."
  },
  "evaluateAnswer": {
    "description": "Оценка ответа на вопрос валидации",
    "prompt": "Оцени ответ пользователя..."
  },
  "generateVerdict": {
    "description": "Генерация вердикта AI",
    "prompt": "На основе бизнес-идеи..."
  }
}
```

#### 4. **dialog** - Промпты для диалога
```json
{
  "generateQuestions": {
    "description": "Генерация наводящих вопросов",
    "prompt": "Ты эксперт по анализу бизнес-идей..."
  },
  "finalAnalysis": {
    "description": "Создание финального анализа",
    "prompt": "Ты эксперт по анализу бизнес-идей..."
  }
}
```

#### 5. **api** - Промпты для API
```json
{
  "chatContext": {
    "description": "Контекст для чата с AI",
    "prompt": "${currentModule.systemPrompt}..."
  },
  "generalContext": {
    "description": "Общий контекст для AI",
    "prompt": "${currentModule.systemPrompt}..."
  }
}
```

## Переменные в промптах

Промпты поддерживают подстановку переменных в формате `${variableName}`:

### Доступные переменные

#### Общие переменные
- `${appState.userIdeaText}` - идея пользователя
- `${appState.projectData.idea}` - данные проекта

#### Переменные модулей
- `${currentModule.title}` - название текущего модуля
- `${currentModule.systemPrompt}` - системный промпт модуля

#### Переменные топиков
- `${topic.title}` - название топика
- `${dynamicLearningState.currentTopic.title}` - текущий топик

#### Переменные диалога
- `${dialogState.userIdea}` - идея пользователя в диалоге
- `${dialogSummary}` - сводка диалога

#### Переменные валидации
- `${question}` - вопрос валидации
- `${userAnswer}` - ответ пользователя
- `${validationState.totalScore}` - итоговый балл

## Использование в коде

### Получение промпта

```javascript
// Получить промпт по категории и типу
const promptData = window.getPrompt('validation', 'generateQuestions');

// Получить системный промпт модуля
const systemPrompt = window.getModuleSystemPrompt('validation');

// Получить форматированный промпт с переменными
const formattedPrompt = window.getFormattedPrompt('chat', 'learningPlan', {
    topic: { title: 'Методология валидации' },
    currentModule: { title: 'Валидация идеи' },
    ideaData: 'Моя бизнес-идея...'
});
```

### Обновление промпта

```javascript
// Обновить промпт
window.updatePrompt('validation', 'generateQuestions', {
    prompt: 'Новый промпт для генерации вопросов...',
    description: 'Обновленное описание'
});
```

### Экспорт промптов

```javascript
// Экспортировать все промпты
const exportedPrompts = window.exportPrompts();

// Получить статистику
const stats = window.getPromptStats();
```

## Настройки промптов

### Параметры в разделе settings

```json
{
  "settings": {
    "maxResponseLength": 2000,
    "defaultLanguage": "ru",
    "responseFormat": "markdown",
    "temperature": 0.7,
    "maxTokens": 4000
  }
}
```

### Параметры:
- `maxResponseLength` - максимальная длина ответа
- `defaultLanguage` - язык по умолчанию
- `responseFormat` - формат ответа (markdown, text)
- `temperature` - креативность AI (0.0 - 1.0)
- `maxTokens` - максимальное количество токенов

## Резервные данные (fallbacks)

```json
        "question": "Какие принципы вы поняли?"
      }
    ]
  }
}
```

## Лучшие практики

### 1. Структурирование промптов
- Используйте четкие описания
- Группируйте связанные промпты
- Добавляйте комментарии к сложным промптам

### 2. Переменные
- Используйте переменные для динамического контента
- Проверяйте наличие переменных перед использованием
- Документируйте доступные переменные

### 3. Форматирование
- Используйте markdown для структурированных ответов
- Ограничивайте длину ответов
- Добавляйте инструкции по форматированию

### 4. Обработка ошибок
- Всегда предоставляйте резервные данные
- Логируйте ошибки загрузки промптов
- Используйте встроенные промпты как fallback

## Миграция и обновления

### Обновление версии

1. Измените версию в `prompts.json`
2. Обновите `lastUpdated`
3. Добавьте новые промпты или измените существующие
4. Протестируйте изменения

### Совместимость

- Система автоматически загружает встроенные промпты при ошибках
- Поддерживается обратная совместимость
- Новые поля игнорируются старыми версиями

## Безопасность

### Рекомендации

- Не включайте конфиденциальные данные в промпты
- Проверяйте промпты перед развертыванием
- Используйте переменные для динамического контента
- Ограничивайте длину промптов и ответов

### Валидация

- Проверяйте JSON на корректность
- Валидируйте переменные перед подстановкой
- Тестируйте промпты с разными данными
